            How it works
            
  
              
    
            1. Intake: Gemini on Agent Platform reads the complaint (any language) and compares the defect photo with a golden sample. It proposes a box; the engineer confirms it.
              2. 
    
            2. Investigator: an ADK agent tests hypotheses with tools over BigQuery: the is / is-not analysis (BigQuery ML contribution analysis plus a two-proportion test), a confounder split, process-parameter excursions and inspection changes.
              3. 
    
            3. Challenger: fixed rules reject a draft with no escape cause, uncited claims, numbers not found in evidence, or blame on people without a stratified effect.
              4. 
    
            4. Writer: Gemini drafts the 8D in English and Japanese. Every percentage and lot count must match a tool result, or the template text is used.
              5. 
    
            5. Sign-off: you approve D2–D5. Export is locked until then.
